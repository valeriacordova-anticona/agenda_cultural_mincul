Agenda Cultural – Análisis Exploratorio

Este sitio presenta los resultados de un ejercicio de extracción y procesamiento de datos realizado como parte del curso Extracción y Procesamiento de Datos (Media Lab – PUCP).

Los datos fueron obtenidos mediante scraping estático de una agenda cultural y procesados con Python para identificar patrones básicos en los títulos de las actividades.
